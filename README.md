<section>
  <h2>About Smart Text Diff</h2>

  <p>
    Smart Text Diff is a modern, browser-based text comparison and review utility designed
    to help users quickly identify differences between two versions of text. The application
    operates entirely on the client side, ensuring that all data remains private and is
    processed locally within the user's browser without requiring any server communication.
  </p>

  <p>
    The tool provides a clean dual-panel interface where users can paste or type an
    original version of text alongside a modified version. It then performs real-time
    comparison and visually highlights additions, deletions, and modifications, making
    document reviews, code comparisons, content auditing, and change tracking significantly
    easier.
  </p>

  <h3>Key Features</h3>

  <ul>
    <li>Real-time text comparison with instant visual updates.</li>
    <li>Multiple comparison modes including Line, Word, and Character level diffing.</li>
    <li>Color-coded highlighting for added, removed, and modified content.</li>
    <li>Live statistics showing counts of additions, deletions, and changes.</li>
    <li>Side-by-side comparison interface for better readability.</li>
    <li>Synchronized scrolling for easy navigation through large documents.</li>
    <li>Built-in export functionality to copy diff results to the clipboard.</li>
    <li>Dark and Light theme support for improved user experience.</li>
    <li>Responsive design optimized for desktop, tablet, and mobile devices.</li>
    <li>Keyboard shortcuts for faster workflow and productivity.</li>
    <li>Privacy-focused architecture with 100% local processing.</li>
  </ul>

  <h3>Technology Overview</h3>

  <p>
    The application is built as a single self-contained HTML file using standard web
    technologies including HTML5, CSS3, and Vanilla JavaScript. No external frameworks
    or backend services are required for core functionality.
  </p>

  <p>
    A custom diff engine powered by the Longest Common Subsequence (LCS) algorithm is
    used to detect similarities and differences between text inputs. The comparison engine
    supports line-level analysis as well as more granular word and character-level
    comparisons to provide accurate change visualization.
  </p>

  <h3>Use Cases</h3>

  <ul>
    <li>Document revision and proofreading.</li>
    <li>Source code comparison and review.</li>
    <li>Configuration and YAML file validation.</li>
    <li>Content auditing and compliance checks.</li>
    <li>Version tracking and change analysis.</li>
    <li>Technical documentation reviews.</li>
    <li>Contract and policy comparison.</li>
    <li>Educational and research purposes.</li>
  </ul>

  <h3>Benefits</h3>

  <p>
    Smart Text Diff eliminates the need for complex software installations while providing
    a fast, lightweight, and secure comparison experience. Its intuitive interface,
    efficient diff algorithm, and fully offline operation make it an ideal solution for
    professionals, developers, analysts, writers, and anyone who regularly works with
    multiple versions of text-based content.
  </p>

  <p>
    By combining performance, usability, and privacy into a single portable application,
    Smart Text Diff offers a reliable and efficient way to analyze textual differences
    and streamline review workflows.
  </p>
